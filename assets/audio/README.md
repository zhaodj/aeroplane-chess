# Audio Assets

Most audio files in this folder are from Kenney asset packs released under
Creative Commons Zero (CC0). They can be used in personal and commercial
projects without mandatory attribution.

- `bgm.ogg`: generated locally by `scripts/generate-bgm.py` with no
  third-party samples.
- `victory.ogg`: Kenney Music Jingles
  https://www.kenney.nl/assets/music-jingles
- `dice.ogg`, `move.ogg`, `launch.ogg`, `event.ogg`, `shield.ogg`:
  Kenney Interface Sounds
  https://www.kenney.nl/assets/interface-sounds
- `collision.ogg`: Kenney Impact Sounds
  https://www.kenney.nl/assets/impact-sounds
